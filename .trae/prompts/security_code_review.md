# 安全代码审查

对指定代码执行安全专项审查，输出结构化发现。审查标准以 `.trae/rules/security_structure.md` 为准。

## 审查范围

按风险优先级逐项检查：

1. 命令注入（shell 拼接、参数注入）
2. SSRF 与回调类请求
3. 路径遍历与文件路径处理
4. 不安全的文件读写
5. 凭据与敏感信息泄露（日志、输出、落盘）
6. 外部进程执行（exec 使用方式、超时与取消）
7. 资源耗尽（内存、并发、无界增长）
8. 竞态条件
9. 不安全的反序列化
10. TLS 校验与证书处理
11. 重定向处理
12. 授权与目标范围校验

## 发现格式

每条发现必须提供：

- 严重性（高 / 中 / 低）
- 受影响文件与函数
- 根因
- 触发条件
- 影响
- 修复建议

## 要求

- 只报告可成立的发现：每条必须说明触发条件，不报告纯理论问题。
- 引用 `security_structure.md` 的对应条款作为判定依据。
- 审查结论用中文书写，术语保留英文。
- 不得修改代码，除非被明确要求。
